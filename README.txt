CDN LAB ACTIVITY 4
==================

FILES
-----
index.html       - static website to deploy
cdn-network.svg  - local image used by the page

BEFORE DEPLOYING
----------------
1. Open index.html.
2. Replace:
   - YOUR NAME HERE
   - YOUR ID HERE
   - ENTER YOUR ACTUAL TIME
3. Save the file.

DEPLOYMENT
----------
Use Firebase Hosting or Netlify as required by the lab sheet.

AFTER DEPLOYMENT
----------------
1. Open the live URL.
2. Take a screenshot with the browser address bar visible.
3. Press F12 -> Network -> refresh -> click the HTML request -> Headers.
4. Take a screenshot of Response Headers.
5. Put a red box around a CDN-related field such as Server, Via,
   X-NF-Request-ID, cache-control, or age.
6. Put the live URL and both screenshots into the report.

IMPORTANT
---------
Do not invent a response-header screenshot. It must come from your
actual deployed site.
